# Smash Việt – Cầu lông 3D

Game cầu lông 3D chạy ngay trên trình duyệt, không cần cài đặt.

**Chơi ngay:** https://loznnhe12.github.io/smashviet/

## Đấu online với bạn bè
- **Tìm trận nhanh:** hai người cùng bấm là gặp nhau.
- **Tạo phòng:** gửi mã 4 chữ số (hoặc link mời) cho bạn bè; bạn bè bấm link hoặc nhập mã ở mục *Đấu online*.
- Hai máy nối thẳng với nhau (WebRTC P2P); máy chủ PeerJS miễn phí chỉ dùng lúc bắt tay.

## Điều khiển
- **Máy tính:** WASD hoặc mũi tên để di chuyển · J = CAO · K hoặc phím cách = ĐẬP · L = NHỎ · giữ phím hướng khi bấm để chọn góc đánh · Esc = menu.
- **Điện thoại:** kéo ngón trái để di chuyển, chạm nút CAO / ĐẬP / NHỎ, vuốt trên nút để chọn hướng. Nên xoay ngang màn hình.
